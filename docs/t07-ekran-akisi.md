## Ekranlar

Tablodaki içerikler proje planından gelir. Son sütuna kendi çiziminde düğmelerin açtığı ekranları yaz.

| Ekran | Çizimde gösterilecek içerik | Düğme ve hedef ekran |
|---|---|---|
| Ana Galeri | Arama, altı filtre seçeneği, iki sütunlu fotoğraflar, duygu rozeti, + | |
| Kamera ve Anı Ekle | Kamera veya galeri, önizleme, renk, konum, hava, duygu, not, kaydet | |
| Anı Detayı ve Düzenleme | Büyük fotoğraf, tarih, konum, not, duygu, o günün ve bugünün havası, düzenle, sil, paylaş | |
| AI Zaman Karşılaştırma | Orijinal ve bugünkü görsel, karşılaştırma kaydırıcısı, yerel efekt kullanıldığında açıklama | |
| Harita | Anıların konum işaretleri, seçilen anıyı açma | |
| Albümler | Manuel albüm oluşturma, anı ekleme veya çıkarma, albümü silme, renk, duygu, şehir ve aya göre otomatik albümler | |
| Temizlik Önerileri | Ekran görüntüleri, bulanık kareler, seçme, tutma, sistem onayıyla silme | |
| Sosyal Akış | Paylaşılan anılar, beğeni, yorum, profile erişim | |
| Giriş ve Profil | E-posta ile giriş ve kayıt, oturum açıkken ad ve profil fotoğrafı | |

## Akış kontrolü

Önizlemede veya çizim üzerinde denediğin geçişleri işaretle. Ekran sırası senin tasarımına göre değişebilir.

- [ ] Galeriden yeni anı ekleyip kaydedilen fotoğrafı bulabildim.
- [ ] Anı detayından önce/sonra karşılaştırmasına geçip geri dönebildim.
- [ ] Haritadaki bir işaretten ve bir albümdeki fotoğraftan anı detayına ulaşabildim.
- [ ] Temizlikte bir fotoğrafı tutmayı ve silme onayını iptal etmeyi gösterebildim.
- [ ] Oturum kapalıyken paylaşma, giriş ve ardından paylaşımı onaylama yolunu gösterebildim.
